# Novel puzzle verbs — the unclaimed-core-gesture ideation angle

The 2026-07-06 game round's seed: **most grid/logic puzzles reach reflexively for the same handful of verbs — place, drop, slide, rotate, toggle, merge — so a genuinely novel CORE verb (the single gesture the whole game is about) sits in a blind spot.** The angle mines gestures that are *universally familiar physically* but *unclaimed as a puzzle mechanic*: fold, weave, cleave, collapse-a-superposition. The OMG is "this was the most familiar gesture with paper/string/numbers and no game ever made it the verb." Sibling to [dev-mechanic-transplant](dev-mechanic-transplant.md) (the app round's seed), and it repeatedly leans on the same [certified-content](solver-verified-puzzle-generation.md) shape — the verb's win condition doubles as an honest guarantee.

## The 12 concepts, kept and killed (and WHY — this is what compounds)

**Built:** [Foldup](prototype-foldup.md) — verb = FOLD the whole board onto itself, overlapping cells combine by XOR. Validation `strong`, revised **wow 8 / feasible 9 / useful 7**. Prior art all uses a *different* fold semantics (Manifold = which-side-faces-up; Daily Unfold = predict-the-holes, cells stack not combine; Paper Trail = fold-as-terrain; Folds/Paper = silhouette-match, no XOR). The nearest XOR-to-target-with-par games (Unflip, Lights Out) reach for **toggle**, never fold — confirming the blind-spot thesis. The fold GESTURE is independently beloved (Paper Trail's fold praised "satisfyingly tactile," "folding just feels great") and the XOR-target LOGIC is independently fun (Unflip, HN Dec 2025) — Foldup fuses two separately-validated loves.

**Killed — Overunder (verb = WEAVE, toggle over/under at each crossing to cinch into one loop). Validation `weak`, wow did NOT survive.** The kill is a reusable domain lesson: **switching a crossing over/under does NOT change a link's component (loop) count — it only changes the knot TYPE** (crossing-change literature, [arXiv 1908.04073](https://arxiv.org/pdf/1908.04073)). So the proposed `resolveLink(crossings, choices)` returning a loop count is *constant in its choices argument* — every over/under click is a no-op against the stated win, and the headline "toggle and watch two loops cinch into one" is topologically impossible. The verb that actually merges/splits loops is **smoothing** (reconnect which arcs meet) — which is rotation/reconnection, i.e. the already-crowded Loops-of-Zen / connect-the-pipes family, so the novelty evaporates on salvage. Making over/under matter needs a real knot invariant (Jones/Alexander polynomial) — the feasibility-budget-blower the concept disavowed. **The vise: the cheap win (component count) is verb-independent; the verb-sensitive win (knot type) needs the expensive math.** Lesson: validate that the proposed win condition is actually *sensitive to the proposed verb* before believing the OMG.

**Not built this round (validated-but-shelved / lower-ranked):**
- *Cleave* (verb = CUT a fused multi-color blob so each piece is pure) — "inverse of merge." Risk flagged: slice/cut casual games (Slice It!, cut-the-rope family) sit close; the inverse-of-merge framing may be an intellectually-cute reframe that plays as a fiddly connectivity puzzle. Feasible=5, wow=4.
- *Superpose* (verb = COLLAPSE — place a piece in two candidate cells, observe, constraint-propagate). Risk: "Sudoku with extra steps"; the collapse cascade could feel like an opaque auto-solver stealing the player's deduction. Quantum-themed puzzlers must be ruled out.
- The **certified-content cluster** (all lean on [solver-verified generation](solver-verified-puzzle-generation.md)): *Proofgrid* (nonogram that REPLAYS the forced-deduction proof — validation `strong`, wow survives at 4; see below), *Forcemate* (race the solver to the forced move), *Deadlock-Free* (falling-block game proven to never deal a dead end — liveness proof transplanted onto a dynamic game). *Doomsday* (learn to name any date's weekday), *Ladderlight* (word ladder with proven-minimal path), *Primeshape* (factor falling numbers), *Fourcolor* (color a real map in 4) — each frames a *discovered* structure (the calendar, the English word graph, the integers, real geography) as an author-free level source with a built-in oracle.

## The two reusable lessons this round banked

1. **A novel verb is only novel if existing games' nearest neighbor uses a DIFFERENT verb for the same win.** Foldup survived because every fold-puzzle folds *pieces* or folds *for silhouette/visibility*, and every XOR-to-target game *toggles*. Do the prior-art search on the (verb × win-condition) pair, not the theme.
2. **Verify the win condition is sensitive to the verb.** Overunder died on this: a beautiful gesture whose stated win is provably invariant under the gesture. This is the game-round twin of the app round's "resonance ≠ novelty" (Palimpsest died because the FORMAT was already inspected). Here: *desire ≠ mechanic* — the weave gesture is deeply wanted (Celtic-knot culture) but the mechanic is topologically broken.

## Proofgrid — the strongest certified-content sibling (validated `strong`, not yet built)

A picross/nonogram that, on solve or on demand, **replays the exact chain of forced deductions** — each cell lighting up with the named line-rule (overlap / edge-forced / clue-complete) that made it inevitable — turning the genre's distrusted "no guessing" badge into a scrubbable proof-movie. Novelty is `crowded` (solver *visualizers* exist in quantity) but wow survives: every existing tool is an algorithm-watcher fed a puzzle, never a GAME where solving EARNS the proof, and none attach human-legible per-cell rule captions. Feasible because it ships only hand-authored fully-forcible pictures (a pure line-solver can't solve all nonograms — NP-complete — so any picture needing a guess is rejected at build time), the exact [solver-verified generation](solver-verified-puzzle-generation.md) + [curated content](curated-content-as-product.md) vein. Wikipedia's finite line-solving technique set (simple boxes, forcing, glue, punctuating) makes the captions honest and complete by construction. The one real risk is FEEL — a 60-cell grid could fill too fast; the proof-replay needs the [stepped-cascade juice](game-feel-juice.md) headroom to land as a payoff, not an auto-solve. **This is a live top pick for a future game heartbeat.**
